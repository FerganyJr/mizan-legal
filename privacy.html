Privacy Policy — Mizan (ميزان)

Package ID: com.mizan.finance · Last updated: November 26, 2026 · النسخة العربية · Account Deletion

Mizan is designed with privacy and data minimization at its core. You can use Mizan completely offline in Guest Mode or optionally sign in to sync data across devices and shared partner spaces.

1. Data Stored on Your Device (Offline-First)

All budgets, transactions, categories, goals, debts, and optional receipt images are stored locally on your device in an SQLite database. In Guest Mode, Mizan does not create a cloud account or transmit your personal financial data to external servers.

2. Optional Mizan Cloud Sync & Account Data

  • Authentication: If you choose to sign in (Email OTP or Google Sign-In), we process your email address, user ID, and optional display name via Supabase Authentication.
  • Cloud Database & Security: Synced records (personal cloud wallets, shared wallets, shared goals, and space memberships) are stored in Supabase (eu-central-1), encrypted in transit (TLS) and at rest, and protected by strict Row-Level Security (RLS) so only authorized space members can access their own records.
  • Receipt Images: Receipts attached in synced spaces are stored in a private Supabase Storage bucket (receipts) scoped strictly to the owning space.

3. Opt-In Gemini AI Financial Coach

The AI Financial Coach feature is strictly opt-in and requires your explicit in-app consent before any request is sent. When you request an AI review:

  • Mizan sends only anonymized numeric aggregates (cycle spend, budget limits, 50/30/20 bucket ratios, debt APRs/balances, and goal totals).
  • Mizan never sends person names, transaction notes, receipt images, email addresses, or raw transaction lists.
  • Requests are routed through our Supabase Edge Function to Google's Gemini API with store: false so conversation state is not persisted server-side.

4. Optional Crash Diagnostics (Firebase Crashlytics)

Crash reporting via Firebase Crashlytics is disabled by default and only enabled if you explicitly opt in. When enabled, only sanitized technical crash stack traces and device metadata are sent—never financial amounts, transaction notes, or receipts.

5. Zero Ads & Zero Data Selling

Mizan displays zero advertisements, uses zero third-party ad-tracking SDKs, and never sells, rents, or shares your financial data with data brokers.

6. Your Rights: Export & Permanent Deletion

  • Export anytime: Export your complete financial history to JSON or CSV from Manage.
  • Delete anytime: Delete your local device data or permanently delete your Mizan Cloud account, synced records, and uploaded receipts directly inside the app. Full instructions are available on our Account & Data Deletion page.

7. Contact

For privacy questions or support, please open an issue or contact the developer via the Mizan GitHub repository.

سياسة الخصوصية — تطبيق ميزان (Mizan)

المعرّف: com.mizan.finance · آخر تحديث: 26 نوفمبر 2026 · English Version · حذف الحساب

صُمّم تطبيق ميزان ليكون آمنًا ويحترم خصوصيتك من البداية. يمكنك استخدام التطبيق بالكامل بدون إنترنت (وضع الضيف)، أو تسجيل الدخول اختياريًا لمزامنة بياناتك أو مشاركة المحافظ مع الشريك.

1. البيانات المحفوظة على جهازك

تُحفظ جميع الميزانيات والمعاملات والأهداف والديون وصور الفواتير محليًا على جهازك في قاعدة بيانات SQLite. في وضع الضيف، لا يتم إرسال أي بيانات مالية إلى أي خادم خارجي.

2. المزامنة السحابية الاختيارية (Mizan Cloud)

  • تسجيل الدخول: عند اختيار تسجيل الدخول (عبر البريد الإلكتروني OTP أو Google)، نستخدم بريدك الإلكتروني ومعرّف الحساب واسم العرض الاختياري عبر Supabase Auth.
  • أمان البيانات: تُحفظ البيانات المتزامنة في Supabase (eu-central-1) مشفّرة أثناء النقل (TLS) وعند التخزين، مع تطبيق قواعد أمان صارمة على مستوى الصفوف (RLS) تضمن عدم وصول أي مستخدم لبيانات لا يشارك فيها.
  • صور الفواتير: تُحفظ الفواتير المرفوعة في مساحات متزامنة داخل مخزن خاص (receipts) مقصور على أعضاء المساحة فقط.

3. المستشار المالي الذكي (اختياري بموافقتك)

ميزة المستشار المالي بالذكاء الاصطناعي اختيارية بالكامل وتتطلب موافقتك الصريحة داخل التطبيق قبل إرسال أي طلب:

  • يرسل التطبيق أرقامًا إجمالية مجهولة الهوية فقط (إجمالي الصرف، حدود الميزانية، نسب الفئات، نسب الفائدة وأرصدة الديون، وإجمالي الأهداف).
  • لا يتم إرسال أسماء الأشخاص أو ملاحظات المعاملات أو صور الفواتير أو البريد الإلكتروني أو سجل المعاملات الخام أبدًا.
  • تُعالج الطلبات عبر خادمنا الوسيط إلى Gemini API مع تفعيل store: false لعدم الاحتفاظ بسجل المحادثة.

4. تقارير الأعطال الاختيارية (Firebase Crashlytics)

إرسال تقارير الأعطال عبر Firebase Crashlytics معطّل افتراضيًا ولا يُفعّل إلا بموافقتك الصريحة. عند التفعيل، تُرسل تفاصيل تقنية منقّحة للأعطال فقط دون أي مبالغ مالية أو ملاحظات أو فواتير.

5. بدون إعلانات وبدون بيع للبيانات

تطبيق ميزان خالٍ تمامًا من الإعلانات وأدوات التتبع الإعلانية، ولا يبيع أو يشارك بياناتك المالية مع أي طرف ثالث.

6. حقوقك: التصدير والحذف النهائي

  • التصدير: يمكنك تصدير بياناتك بصيغة JSON أو CSV في أي وقت من صفحة الإدارة.
  • الحذف النهائي: يمكنك مسح بيانات الجهاز أو حذف حسابك السحابي وجميع بياناته وفواتيره نهائيًا من داخل التطبيق. راجع صفحة حذف الحساب والبيانات.

7. التواصل

للاستفسارات المتعلقة بالخصوصية، يمكنك التواصل عبر مستودع ميزان على GitHub.
